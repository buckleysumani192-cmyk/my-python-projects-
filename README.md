### 2. irrigation.py - PNG Smart Irrigation System
This project helps PNG farmers calculate water needs for their gardens.

**How it works:**
- User enters crop type (kaukau, taro, corn)
- User enters garden size in m2
- User enters soil type (sandy, clay, loam)
- Program calculates daily water needed in liters

**Example:**
For 10m2 of kaukau on loam soil:
> You need 50.0 liters per day
> Water in morning: 25.0L
> Water in evening: 25.0L

**Why it matters for PNG:**
Helps farmers in villages save water and grow better crops. Sandy soil needs more water, clay soil needs less. This simple tool can help food security in PNG.
